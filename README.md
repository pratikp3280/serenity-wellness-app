
# Serenity – Wellness Web Application

Serenity is a wellness-oriented web application designed to provide an engaging interface for mood selection, guided breathing activities, wellness programs, and personal well-being experiences.

## Current Development Status

- [x] React frontend development
- [x] Vite project setup
- [ ] Backend development
- [ ] Database integration
- [ ] Authentication
- [ ] Full-stack integration

## Technology Stack

### Frontend
- React.js
- JavaScript (JSX)
- Vite
- CSS / Tailwind CSS
- Framer Motion
- Lucide React

### Planned Backend
- Java
- Spring Boot
- MySQL
- REST APIs

## Running the Frontend

Navigate to the Frontend directory:

```bash
cd Frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Future Development

The project will gradually evolve into a full-stack application with backend services, database persistence, authentication, mood tracking, breathing session history, and progress tracking.
